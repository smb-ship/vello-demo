# Practice demo: healthcare SaaS landing page

Original portfolio exercise inspired by a client brief. NOT the VelloHealth website, not affiliated with VelloHealth, and not built in Framer. All copy, numbers, logos, and "screenshots" are made-up placeholders.

Run it: `npm install` then `npm run dev`, and open the address shown (usually http://localhost:5173).

Routes: `/` home, `/hr1` landing page, `/insights` renamed page, `/resources` redirects to `/insights`.
Image fix demo: see the comment above `ROLES` in `src/pages/Home.jsx`.
